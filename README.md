# 🚀 Trabajo Integrador - Mi Perfil Profesional

Este proyecto es una página web personal desplegada en **GitHub Pages**. Fue desarrollado como el trabajo integrador de la materia Emprendedurismo para la carrera de *Tecnicatura Universitaria en Programación Full Stack*.

* **CSS3** - Estilos visuales, diseño responsivo y efectos interactivos.
